# TimberWindowLogistics

Simple app for planning **production** and **delivery** of wooden window frames.

## Run

Open `index.html` in your browser.

## Features

- Add wooden window frame orders (customer, dimensions, wood type, quantity, due date, address)
- Track order status from **Planned** to **Delivered**
- View live production and delivery metrics:
  - total frames
  - in production
  - ready for delivery
  - late orders
- Remove completed/cancelled orders
